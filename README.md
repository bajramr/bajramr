## About me

I build web interfaces and turn practical development lessons into articles, code examples and video tutorials. My work brings together frontend development, web design and WordPress.

I enjoy explaining the small decisions behind an interface: how its HTML is structured, how its layout adapts and how its JavaScript handles real situations.

- **Building:** frontend projects, WordPress websites and small browser experiments.
- **Sharing:** practical HTML, CSS and JavaScript tutorials.
- **Exploring:** browser APIs, accessibility and web performance.
- **Contributing:** technical book reviews and community learning sessions.

## From the Playground

### Basic JavaScript Device Detection

A small exercise for complete beginners: read a browser's user-agent, check text patterns and display a message using `if / else if`.

The example explores possible phone, tablet and desktop results while explaining why those guesses are not reliable hardware identification.

**Built with:** HTML · JavaScript
